## 不应误加或误删

- 未达标不是新增的强制失败页；当前八日统一收官，未达标仍能继续无尽。
- `GuideBtn` 在当前设置场景中隐藏。攻略内容存在，但不把重新展示入口当成已有功能要求；重玩新手关必须保留。
- 设计图中的数字只是示例，接线后必须来自游戏状态，所有文案仍走 `Loc.gd`。
- 三张总览是代表状态，不等于所有动态状态图已绘制；禁用、孵化中/领取、满级、双目标达标、倒计时、分享中、中英文和字号变体需要实现阶段逐项验收。

## 手机验收（尚未执行）

1. 信封一次点开不闪关；读完红点消失；结算期间仍能打开。
2. 语言只切一次；音效和环境音独立切换；三档字号不遮字；面板内部点击不关闭。
3. 长按收蛋/买卖、地图缩放/拖动，与场景按钮互不冲突。
4. 孵化投入、孵化中、次日领取形成完整闭环；烤炉100%完成并能继续下一轮。
5. 日终Dock隐藏且不挡报告按钮；新闻与价格、资产等数据对应。
6. 八日达标/未达标均能分享、再挑战、继续无尽；3秒等待确实生效。
7. 返回菜单、重进、刷新网页后的存档与语言/字号恢复按现有逻辑验证。

静态图片只能审核入口和布局，无法证明触摸防抖、事件路由、计时、音频、存档和网页分享工作正常。
