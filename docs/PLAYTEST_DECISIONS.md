# 玩家数据测试：访谈决策记录

更新：2026-09-17。状态：设计访谈进行中，未开始埋点、问卷或平台发布实施。

## 本轮用户已确认

- 首要目标是首次游玩投入，次要目标是次日回访。
- 招募可以来自朋友、自然流量、游戏群和学校群；项目属于学生项目。截止日期不定，人数能多少是多少。
- 奖励广告是验证继续游玩意愿的重要指标，也被考虑为未来主要盈利方式。
- 六题沿用旧计划：游戏水平、年龄段、性别、同类游戏经验、重试原因、开放建议；后续继续修改。
- 第一次奖励重试弹出问卷；填完后不再要求填写，改为五秒占位等待。
- 问卷未填完就关闭：这次奖励仍发放；稍后仍可再填；一旦提交成功则不能再填。
- 发布顺序：先自有站小测排查问题，再投 CrazyGames 测陌生流量。不与 Poki 并行。
- 挑战第 12、16、20 天考核失败：每个考核日各有一次奖励复活；第一次失败可当天重试，第二次没过不能再复活。第 12 天用过不影响第 16、20 天。
- 未完成问卷：奖励入口再次点开仍弹出问卷（关闭仍发这次复活）；设置里另有反馈入口，只补填、不发复活。提交成功后两处都不再出现问卷，奖励入口改为五秒占位等待。

## CrazyGames 路线（已记录、非平台承诺）

CrazyGames 是先测表现再决定是否正式发行和变现：提交审核 → Basic Launch（7～21 天，至少 7 天且 500 次游玩后结束，未满则第 21 天结束）→ 被选中后才 Full Launch（需 SDK，才有广告分成）。500 次游玩不是 500 个独立玩家；考察期结束不等于自动通过。Basic 阶段广告关闭。这条路线先回答「陌生玩家是否愿意留下来玩」，不能在 Basic 阶段验证真实广告复活或收入。

Poki 需申请开发者访问，外部统计要批准，合作说明涉及网页独家。少操心地试一轮时，先评估 CrazyGames，不把 Poki 当本轮并行选项。

奖励观察分三层，不得合并：看见入口后点击；完成问卷或五秒等待；真实广告完成并复活后继续玩。朋友填问卷与陌生玩家看广告动机不同，按来源和奖励类型分开看。平台默认指标不知道卡在第 12 还是第 20 天，自有站仍保留少量通关与重试事件。

## 当前代码事实

- 已有普通八日模式、第9–20天挑战模式、无尽模式。旧计划中“没有挑战模式”的描述已过时。
- 本地未发现统计SDK或问卷实现。
- 日结和普通八日失败有恢复当天早晨入口；挑战考核失败没有该入口。
- 当前所谓广告入口只等待约0.9秒后恢复当天，没有真实广告播放；五秒等待与问卷尚未实现。
- `_continue_endless_from_finale()` 现为普通通关后进入挑战，埋点按行为含义命名。

## 分析边界

- 问卷完成、五秒等待完成与真实广告完播分别统计，不将前两者用于证明真实广告完播率或广告收入。
- 玩家招募来源分别标记，避免把朋友/学校协助测试与陌生自然流量混为同一群体。
- 六题问卷通过奖励重试入口获取的回答具有选择性，不能默认代表所有玩家。关闭未提交仍发奖励，因此「问卷完成率」不能当成「复活发放率」。
- “打到终局”与“达到通关条件”分开；局数、尝试次数和去重玩家数分开。
